Ausgewählte Arbeit & Projekte

Medizinische SaaS-Plattform

Migration der Produktiv-Infrastruktur einer medizinischen Plattform von Supabase Cloud auf einen selbst gehosteten Hetzner VPS.

  • Docker-Compose-Stack mit 14 Services: API Gateway, Auth, REST API, Realtime, Storage, Connection Pooling, Reverse Proxy und Logging.
  • Kein kritischer Ausfall während des Migrations-Umschnitts.
  • Behebung von Realtime-Synchronisationsfehlern zwischen mobilen Clients und Web-Admin-Portal.
  • PostgreSQL-Stabilisierung mit Supavisor-Connection-Pooling sowie UFW, SSH-Härtung, Secrets-Handling und Netzwerkisolierung.
